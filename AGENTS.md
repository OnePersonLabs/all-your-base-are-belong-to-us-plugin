# All Your Base development

This repository ships the independent `all-your-base` plugin and its
`$all-your-base:assimilate` skill. Keep the skill self-contained and preserve
its contained/campaign distinction, source attribution and recovery guarantees.

Use `$onepersonlabs:github-workflow` for actionable work and delivery status in
OnePersonLabs/all-your-base-are-belong-to-us-plugin. Existing skill references
and specifications own meaning and evidence. Keep active work, decisions and
recovery in `.work/current-work.md`; do not create a second backlog.
Use `$onepersonlabs:setup-repo-workflow` for explicit setup or migration only.

Work serially on the selected branch with one primary issue through landing
and up to two useful bounded helpers. Preserve unrelated dirty work. Make
coherent checked task-owned commits; publication and installation require the
task's authority. New branches and PRs require an explicit choice. Review the
full task series from its frozen baseline, retain builder repair ownership and
rerun checks only when their inputs or relevant evidence change. Use native
independent review when consequence or unresolved uncertainty justifies it.

Run existing contract and unit checks at a coherent integration boundary and
the installed-copy checkpoint for shipping changes. Report successful checks
briefly and failures with useful evidence. Do not add skill invocation tests or
AI-consuming evaluations without explicit permission. A local commit, published
source, installed plugin and session-loaded skill are separate states.

On resumption, inspect Git state and the current-work checkpoint. Preserve
accepted scope, failed hypotheses, cumulative budget and the next safe action.
After two failed repair cycles without progress on the same observable problem,
stop dependent repairs and reassess the premise under the engineering contract.
This workflow installs no unattended agent or scheduler.
